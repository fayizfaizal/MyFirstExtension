# Simple Message Popup - Chrome Extension

A lightweight Google Chrome extension built using Manifest V3 that displays a custom message and GIF when clicked.

## 🚀 Features
- Built with **Manifest V3**
- Displays custom HTML markup and animated GIF content
- Instant popup action on toolbar click

## 📦 How to Install Locally
1. Clone or download this repository to your computer.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked** and select the folder containing these files.
5. Pin the extension to your browser toolbar and click the icon to view.

## 🛠️ Built With
- HTML5
- JSON (Chrome Extension Manifest V3)
